# Website of the International Workshop on Software Engineering for Systems-of-Systems and Software Ecosystems (SESoS)

This repository contains the website and related archive for the International Workshop on Software Engineering for Systems-of-Systems and Software Ecosystems (SESoS).

## Contents

- `index.html`: Main website entry point.
- `about/`: SESoS/WDES overview and event history.
- `2027/`: Current workshop website.
- `2013/` through `2026/`: Archived workshop websites and materials.

Most workshop pages are self-contained static HTML files with local CSS and image assets. Historical directories may contain legacy files and older naming conventions.

## Preview Locally

Because the site is static, it can be previewed with any local Web server.

## Updating The Site

1. Edit the relevant HTML page and its local assets.
2. Keep links relative when linking to files within the repository.
3. Preserve the directory structure for archived editions.
4. Check links and assets locally before publishing.

The year folders are intended to remain historical snapshots, so changes to older editions should be limited to corrections such as broken links, missing assets, or factual updates requested by the workshop organizers.

## Deployment

The repository is structured as a static website and can be deployed to GitHub Pages or any static hosting service. No server-side runtime is required for the converted workshop pages.
